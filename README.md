# 🇺🇸 USA High-Performance Protocol · Rutina Diaria Full Body

App web interactiva y manual en PDF para entrenamiento diario de cuerpo completo (30–45 minutos) sin implementos, diseñada para atletas acostumbrados a alta exigencia y para contrarrestar la postura del ciclismo.

🌐 **App en vivo:** [https://raimanuel-ctrl.github.io/rutina-usa/](https://raimanuel-ctrl.github.io/rutina-usa/)  
📄 **Manual en PDF:** [Descargar Rutina_USA_FullBody.pdf](Rutina_USA_FullBody.pdf)  
📖 **Guía Técnica:** [Rutina_USA_NoEquipment_Guia.md](Rutina_USA_NoEquipment_Guia.md)

---

## 📱 Cómo Instalar en iPhone (como App nativa)

1. Abre el enlace en **Safari**: `https://raimanuel-ctrl.github.io/rutina-usa/`
2. Toca el botón de **Compartir** (`📤`).
3. Selecciona **"Agregar a pantalla de inicio"** (*Add to Home Screen*).
4. ¡Listo! Se abrirá a pantalla completa sin barras de navegador.

## ✨ Características
* **Sistema Ondulante A / B / C:**
  * **Día A:** Fuerza de Empuje + Cadena Anterior (Pectoral, Deltoides, Tríceps, Cuádriceps y Core).
  * **Día B:** Tracción Corporal & Cadena Posterior (Dorsales, Romboides, Glúteos, Isquios y Oblicuos).
  * **Día C:** "Ciclista Reset" & Movilidad Metabólica (30 min).
* **Cronómetro y Descansos con Sonido Offline:** Temporizador con bips y sonido generado por Web Audio API.
* **Historial Permanente y Racha:** Registro de sesiones finalizadas con valoración y racha de días activos.
